# SwapSkill Backend

The backend service for SwapSkill, providing robust API endpoints and data management.

## Key Features
- **RESTful API**: Secure and fast API routes for frontend communication.
- **Admin Panel**: Built-in administration panel for managing users and platform data.
- **Authentication**: Token-based authentication for secure access.
- **High Performance**: Ready for Laravel Octane to ensure maximum request handling speeds.

## Tech Stack
- **Framework**: Laravel 13 (PHP 8.3)
- **Admin Panel**: Filament 5.5
- **Authentication**: Laravel Sanctum
- **Performance**: Laravel Octane
